## Project setup

### Installer les dépendances avec la commande ci-dessous dans {votre_dossier_racine}/projet2/frontend ainsi que dans {votre_dossier_racine}/projet2/backend

```


```

Pour le frontend :
```
npm run serve
```
Pour le backend :
```
node server.js
```
